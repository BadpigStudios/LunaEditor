Algunas cosas que debes saber.

¿Qué necesito para usar Luna?

Una PC con Windows 10 u 11 y un procesador Intel o AMD x64. Extrae toda la descarga portátil y conserva las carpetas codecs, soundfonts e instruments junto a Luna.exe. Las ediciones Windows N necesitan Media Feature Pack de Microsoft.

¿Luna es gratis?

Sí. Luna es gratis y está en desarrollo activo. Este repositorio de GitHub aloja su sitio web; tus comentarios y reportes de errores reproducibles son bienvenidos.

¿Puedo conservar mis proyectos de Luma?

Sí. Luna es el nuevo nombre de Luma. Los proyectos .luma se siguen abriendo; Guardar y Guardar como crean archivos .luna. Tus preferencias siguen siendo compatibles. La paleta predeterminada anterior se actualiza al nuevo tema lunar.

¿Luna incluye herramientas musicales?

Sí. Crea patrones en el editor de notas, edita notas y su intensidad, importa MIDI y elige sintetizadores incluidos, paquetes de muestras WAV o un instrumento SoundFont 2.

¿Puedo usar Luna en Linux o Android?

Aún no. Linux está planeado como alfa experimental; Android también está en planificación. El desarrollo de estas versiones no ha comenzado y no hay fechas asignadas. Consulta el plan de plataformas para conocer el alcance propuesto.

¿Dónde puedo reportar un problema?

Usa GitHub Issues. Incluye tu versión de Windows, los pasos para reproducir el problema y los mensajes de error relevantes.
