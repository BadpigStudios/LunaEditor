EXPERIMENTAL-ALPHA · PLANNED

Linux, one working edit at a time.

Start with a focused desktop workflow, then expand only after preview, project compatibility and export are reliable. The experimental-alpha label will remain explicit throughout the initial Linux releases.

Proposed first scope

  • Import video, audio and images; arrange visual and audio tracks.
  • Trim, split, move, undo and save .luna projects.
  • Basic transforms, keyframes, titles, captions and transitions.
  • Synchronized preview and a small set of tested video/audio export formats.

Before a downloadable alpha

  • Validate on an Ubuntu LTS x86_64 baseline, with Wayland and X11 sessions.
  • Test file access, recovery, audio devices, scaling and graphics fallback.
  • Publish a clear supported-feature list and known limitations.
  • Preserve unsupported project data and explain export limitations.
PLANNED

Android, designed for your hands.

A phone or tablet should feel like its own editing tool. The proposal pairs the shared C++ editing core with a native, adaptive Android interface, rather than shrinking the desktop window.

Proposed first scope

  • Local video, audio and image import through Android's file picker.
  • Touch-friendly timeline selection, trim, split and move controls.
  • Basic transforms, keyframes, audio gain and reliable preview.
  • MP4 export with progress, cancellation and clear device capability limits.

Before a mobile release

  • Test real ARM64 phones and tablets, with adaptable layouts.
  • Handle storage permissions, rotation and interrupted app sessions.
  • Measure memory use, audio sync, battery use and sustained performance.
  • Decide distribution and signing before offering an APK or store listing.
PROPOSED ORDER

Evidence before expansion.

  1. Shared foundations. Separate platform-specific UI, media, audio and file access from the reusable editing core. Keep Windows behavior covered by tests.
  2. Linux experimental alpha. Prove a small desktop edit-to-export workflow and document its limits.
  3. Android foundation. Prove media access, touch interaction and synchronized preview on physical devices.
  4. Broader compatibility. Expand effects and editing tools only after project round trips and rendering checks pass.

Desktop feature parity is not promised for either first release. These are proposed milestones, not a delivery schedule.
