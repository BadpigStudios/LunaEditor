A few things to know.

What do I need to run Luna?

A Windows 10 or 11 PC with an x64 Intel or AMD processor. Extract the entire portable download and keep the codecs, soundfonts, and instruments folders beside Luna.exe. Windows N editions need Microsoft's Media Feature Pack.

Is Luna free to use?

Yes. Luna is free to use and is in active development. This GitHub repository hosts its website; feedback and reproducible bug reports are welcome.

Can I keep my existing Luma projects?

Yes. Luna is the new name for Luma. Older .luma projects still open; Save and Save As write .luna files. Customized preferences remain compatible. The old default palette moves to the new lunar theme.

Does Luna include music tools?

Yes. Create music patterns in the piano roll, edit notes and velocity, import MIDI, and choose bundled synths, WAV sample packs, or a SoundFont 2 instrument.

Where can I report an issue?

Use GitHub Issues. Include your Windows version, the steps to reproduce the problem, and any relevant error message.
